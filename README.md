### 2. ft_printf (Printf Fonksiyonu) 📝(./ft_printf/)

**Durum:** Başarıyla Geçti 100/125 ✅

**Açıklama:** Bu proje, C'nin meşhur `printf` fonksiyonunu yeniden hayata geçirmeyi hedefler. Proje, değişken sayıda argüman alabilen (variadic) fonksiyonların nasıl çalıştığını anlamak için harika bir fırsattır. `%c, %s, %p, %d, %i, %u, %x, %X, %%` gibi temel format belirteçlerini işlemesi gerekmektedir.

**Öğrendiklerim:**
* Değişken sayıda argüman yönetimi (`<stdarg.h>` kütüphanesi, `va_start`, `va_arg`, `va_end`)
* Format belirteçlerini ayrıştırma (parsing) ve işleme
* Farklı veri tiplerini (`int`, `char *`, pointer, unsigned int vb.) uygun formatlarda yazdırma
* Sayı sistemleri arasında dönüşüm (örneğin, integer'ı hexadecimal formata çevirme)

**Notlar:** (Buraya projeyle ilgili önemli notlarınızı, karşılaştığınız zorlukları veya çözüm yollarınızı ekleyebilirsiniz.)
